## September 22, 2026 Update

### Comments and Strings

This week I improved the lexer to handle strings and comments.

Because the rules for lexing inside of comments and strings are different than the rules outside them, they need to be identified as soon as possible, so comment and string parsing happens in the first pass of the lexer.

- **Comment Rules:**
    - Starts with `(*`
    - Ends with `*)`
    - Contains any characters in between
    - Any sets of `(*` and `*)` inside the comment must form valid comments themselves
    - Unbalanced comment brackets result in a compile-time error

- **String Rules:**
    - Starts with a `"` character, and ends with the next non-escaped `"` character
    - Outside of escape sequences, strings can contain any character other than newline
    - An escape sequence inside the string consists of a `\` followed by one of the following:
        - A single `n`, `t`, `"`, or `\` character
        - A 3-digit number from 000 to 255
        - A `^` character followed by a character with value between 64 and 95 (inclusive)
        - A sequence of whitespace characters followed by another `\`

### Bytes vs Runes

I also changed the lexer to read byte-by-byte instead of rune-by-rune. (`rune` is Odin's type for storing a UTF-8 encoded symbol.) This, along with some helper functions I wrote, made the code significantly simpler to read and write.

The official SML specification uses ASCII instead of Unicode anyway, so this change should help me stay closer to the spec.

### Testing

I created a [test suite](/compiler/tests.odin) to make sure that many different parsing scenarios produced the correct output. This helped me out a lot when I was switching from runes to bytes. Odin's test tool also tells you if a memory leak occurs, which is helping me learn about better memory management strategies.

### Sample Case

**Program:**
```sml
(* A helper function for the main Fibonacci function *) 
fun fib' a b n = something;
(* Computes the nth Fibonacci number (* fib 0 -> 0, fib 1 -> 1, ... *) *)
fun fib n = something;
val str = "h\069llo \\ \"world\"";
```

**First step:**
```
COMMENT  (* A helper function for the main Fibonacci function *)
ALPHANUM fun
ALPHANUM fib'
ALPHANUM a
ALPHANUM b
ALPHANUM n
SYMBOLIC =
ALPHANUM something
SPECIAL  ;

COMMENT  (* Computes the nth Fibonacci number (* fib 0 -> 0, fib 1 -> 1, ... *) *)
ALPHANUM fun
ALPHANUM fib
ALPHANUM n
SYMBOLIC =
ALPHANUM something
SPECIAL  ;

ALPHANUM val
ALPHANUM str
SYMBOLIC =
STRING   "h\069llo \\ \"world\""
SPECIAL  ;
```

**Second step:**
```
COMMENT  (* A helper function for the main Fibonacci function *)
RESERVED fun
ALPHA_ID fib'
ALPHA_ID a
ALPHA_ID b
ALPHA_ID n
RESERVED =
ALPHA_ID something
RESERVED ;

COMMENT  (* Computes the nth Fibonacci number (* fib 0 -> 0, fib 1 -> 1, ... *) *)
RESERVED fun
ALPHA_ID fib
ALPHA_ID n
RESERVED =
ALPHA_ID something
RESERVED ;

RESERVED val
ALPHA_ID str
RESERVED =
STRING   "h\069llo \\ \"world\""
RESERVED ;
```
