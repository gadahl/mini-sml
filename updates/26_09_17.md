## September 17, 2026 Update

This week I wrote a **lexer** for my compiler, which takes the source code and iterates over each UTF character. 
It works in two passes:

1) It splits the program into strings that have the same types of characters
    - Alphanumeric, symbolic, whitespace, and reserved language symbols
2) It inspects each string found and gives it further categorization
    - Alphanumeric &rarr; reserved keyword or number or identifier or type variable
    - Symbolic &rarr; reserved keyword or identifier
    - Three successive periods &rarr; ellipsis

I check for all of SML's keywords in this step, even if I don't intend to use all of them.
This makes it easier for me to output good error messages when a user tries to use an unsupported feature.

### Sample Case

**Program:**
```sml
fun f' 0 _ b = b 
  | f' n a b = f' (n-1)(a+b) a;
fun f n = f' n 1 0;
f 10;
```

**First step:**
```
ALPHANUM fun
ALPHANUM f'
ALPHANUM 0
ALPHANUM _
ALPHANUM b
SYMBOLIC =
ALPHANUM b
SYMBOLIC |
ALPHANUM f'
ALPHANUM n
ALPHANUM a
ALPHANUM b
SYMBOLIC =
ALPHANUM f'
SPECIAL  (
ALPHANUM n
SYMBOLIC -
ALPHANUM 1
SPECIAL  )
SPECIAL  (
ALPHANUM a
SYMBOLIC +
ALPHANUM b
SPECIAL  )
ALPHANUM a
SPECIAL  ;
ALPHANUM fun
ALPHANUM f
ALPHANUM n
SYMBOLIC =
ALPHANUM f'
ALPHANUM n
ALPHANUM 1
ALPHANUM 0
SPECIAL  ;
ALPHANUM f
ALPHANUM 10
SPECIAL  ;
```

**Second step:**
```
RESERVED fun
ALPHANUM f'
INT LIT  0
RESERVED _
ALPHANUM b
RESERVED =
ALPHANUM b
RESERVED |
ALPHANUM f'
ALPHANUM n
ALPHANUM a
ALPHANUM b
RESERVED =
ALPHANUM f'
RESERVED (
ALPHANUM n
SYMBOLIC -
INT LIT  1
RESERVED )
RESERVED (
ALPHANUM a
SYMBOLIC +
ALPHANUM b
RESERVED )
ALPHANUM a
RESERVED ;
RESERVED fun
ALPHANUM f
ALPHANUM n
RESERVED =
ALPHANUM f'
ALPHANUM n
INT LIT  1
INT LIT  0
RESERVED ;
ALPHANUM f
INT LIT  10
RESERVED ;
```
